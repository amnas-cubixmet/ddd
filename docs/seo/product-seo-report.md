# Product SEO and evidence

Researched and implemented on 28 November 2026.

The repository catalogue contains 24 photographed outdoor and industrial records and 16 architectural type reference records. Photos document labelled Oreli OSL-NEONA, OSL-NOVAPRO, OFL-ORON, OFL-GlowBee and VIMIO15D150 variants. Exact wattages and IP markings appear where recorded in `src/lib/fixture-photos.ts`. Indexing and Product JSON-LD apply to 13 identified records. The 11 unidentified industrial photos and 16 architectural concepts remain available for direct browsing and enquiry with noindex.

The supplier reference JSON contains 52 historic discovery entries. Use it for provenance and exact matches to the original photographs. It does not establish stock, orderability, ownership, current pricing or specification equivalence for similar model names. Every photographed and architectural detail has product or family selection context and a route to confirm exact model data and quote availability.
