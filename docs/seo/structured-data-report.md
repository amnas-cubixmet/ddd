# Structured data

Researched and implemented on 28 November 2026.

| Entity | Placement | Data source |
| --- | --- | --- |
| Organization and WebSite | Site root graph | Existing public brand, business-card contact channels and configured canonical origin |
| WebPage and BreadcrumbList | Canonical pages and existing reference routes | Rendered headings, navigation and canonical paths |
| CollectionPage and ItemList | Catalogue, evidenced family lists and content hubs | The linked cards or visible items on each page |
| Product | 13 identity-verified photographed model routes | Visible fixture identity, product images, label wattage and recorded ratings |
| Article | Five lighting guides | Article headline, visible brand byline and publication date, publisher and canonical page |

Pricing, stock, ratings, artificial review data and unverified geographic information are excluded. Schema.org Product can describe an enquiry-only product. Google's Product snippet eligibility has additional offer or review criteria. FAQ content is visible on the site and uses HTML disclosure elements. The commercial site does not need FAQ rich result markup.

- [Schema.org Product](https://schema.org/Product)
- [Google Product Snippet eligibility](https://developers.google.com/search/docs/appearance/structured-data/product-snippet)
- [Google Article structured data](https://developers.google.com/search/docs/appearance/structured-data/article)
