# SEO maintenance checklist

Researched and implemented on 28 November 2026.

- Confirm the canonical domain serves this catalogue and redirects its live aliases.
- Verify property ownership, validate the sitemap and inspect important URLs after the release.
- Audit Search Console clicks, impressions, indexing and query-to-page alignment. Compare confirmed enquiry outcomes in a separate lead report.
- Confirm new model name, wattage, photos and exact technical data before enabling indexing. Verify image usage rights and retain source URLs.
- Keep new pages discoverable from a relevant family, application or guide.
- Retest structured data, robots, canonicalisation, image variants and production build when routes change.
- Record real content changes in article modification dates and measure field Web Vitals over time.
- Use the repository skill at `.agents/skills/bharat-lums-seo-engine/SKILL.md`. In clients without automatic skill discovery, open that file at the start of lighting SEO work.
