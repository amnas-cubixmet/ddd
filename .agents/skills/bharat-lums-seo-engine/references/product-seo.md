# Product seo

Match brand, model code, wattage and photographs to primary evidence and the existing catalogue. Classify vendor reference and approved enquiry products separately. Publish verified attributes only. Explain missing ratings, input voltage, stock and other specs through a model-specific enquiry. Describe family-level optics and mounting considerations without attributing them to a model. Include product context through form and WhatsApp links where supported.

## Release gate
- Keep label-derived information distinct from manufacturer datasheet verification and representative designs.
- Assign one canonical keyword intent to each page; do not publish estimated search volumes or duplicate filtered URLs.
- Keep noindex on incomplete reference pages; list only eligible URLs in the sitemap.
- Verify both listing and related card grids at 320px and all supported widths; test combined filters, normalized wattage search and unknown-value sorting.
- Preserve original images and enquiry context. Run lint, typecheck, production build and Playwright before updating main.
