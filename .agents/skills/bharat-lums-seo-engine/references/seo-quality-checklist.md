# Seo quality checklist

Check status, title, description, canonical, single primary H1, social metadata, JSON-LD, sitemap and internal links across every route. Check image files and rendered alt text. Exercise galleries, filtering, menus, keyboard and enquiry validation. Test 320, 375, 390, 430, 768, 1024, 1280, 1440 and 1920 widths plus reduced motion. Compare repeatable LCP, INP and CLS if available and disclose test conditions, unverified claims and any integration gaps.
